Este projeto consiste no desenvolvimento de uma aplicação desktop em C# (WinForms) denominada iShopping, desenvolvida no âmbito da unidade curricular de Desenvolvimento de Aplicações do Curso Técnico Superior Profissional de Programação de Sistemas de Informação.

A aplicação tem como objetivo a gestão de compras domésticas, permitindo ao agregado familiar planear e controlar as suas compras, gerir um orçamento mensal e acompanhar os artigos adquiridos, previstos e não previstos. O sistema suporta múltiplos utilizadores com autenticação por username e password, e todos os dados são persistidos numa base de dados SQL Server através do Entity Framework.

A arquitetura do projeto segue o padrão MVC e inclui funcionalidades como gestão de artigos e tipos de artigo, planeamento e execução de compras, exportação de dados para CSV e uma janela de estatísticas com sugestões de orçamento e lista de compras baseadas no histórico.

### Ferramentas necessárias para o funcionamento do projeto:

- **Desenvolvimento para desktop com .NET (WPF, Windows Forms e aplicativos de consola)**
- **Processamentos e armazenamentos de dados (SQL Server)**

Ao abrir o projeto o utilizador deverá executar o projeto, **em caso de erro** o utilizador deverá clicar com o botão direito na solução do projeto e **Restaurar Pacotes Nuget** -> **CTRL+SHIFT+B** -> **Executar o programa novamente**
